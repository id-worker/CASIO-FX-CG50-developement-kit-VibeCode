Keep that original attribution and license notice with the source data.

Changes in TDIC.DAT: converted TEI to a compact binary format with lossless
block compression; merged matching headwords and parts of speech; removed
markup/stress marks; shortened some entries; added some reverse lookup keys
from English-Russian translations and е/ё spelling variants. The unmodified
source archives remain available at the URLs above. The conversion script
is tools/make_dict.py in the source project.
