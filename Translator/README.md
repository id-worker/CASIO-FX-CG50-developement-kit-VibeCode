# Translator 1.10 — Casio fx-CG50

Офлайн-переводчик RU ↔ EN. Инструкция по установке и клавишам —
[README_RU.txt](README_RU.txt); исходники — `source/`. Для запуска нужны
`Translator.g3a` и `TDIC.DAT` в корне памяти калькулятора. Пользователь
подтвердил работу 1.10 на своём fx-CG50.

**Не публиковать заново до проверки прав:** происхождение фрагмента
`set_menu_return_flag()` и условия/авторство данных словаря требуют
дополнительного выяснения. См. [PUBLICATION_REVIEW_RU.md](PUBLICATION_REVIEW_RU.md),
[LICENSE_DATA.txt](LICENSE_DATA.txt) и `THIRD_PARTY_NOTICES.txt`.
MIT `LICENSE` предназначена для собственного кода и не заменяет условия
словаря, шрифтов и библиотек.

На 28.10.2026 `Translator.g3a` и `TDIC.DAT` уже находятся и в папке
основного репозитория, и в GitHub Release v1.0; они совпадают с оригинальным
архивом 1.10. В этом **дополнении** бинарники не включены, чтобы не
