# Translator 1.11 — Casio fx-CG50

Офлайн-переводчик RU ↔ EN. Инструкция по установке и клавишам —
[README_RU.txt](README_RU.txt); исходники — `source/`. Для запуска нужны
`Translator.g3a` и `TDIC.DAT` в корне памяти калькулятора. В 1.11 интерфейс
преимущественно белый, чёрно-белый; словарь и кириллический шрифт сохранены.

Пользователь подтвердил работу **1.10** на своём fx-CG50. Полная аппаратная
проверка новой **1.11** и именно публикуемого файла не подтверждена; host-тесты
не заменяют реальное устройство. Сохрани прежний `.g3a` перед обновлением.
Словарь `TDIC.DAT` не изменён: SHA-256
`e7f6ab4a090c4f4998cbc5641a7cb06b44c5ef38a5c4c1c9d33f2e303a98cef2`.

**Права требуют дальнейшей проверки:** происхождение фрагмента
`set_menu_return_flag()` и условия/авторство данных словаря не установлены
полностью. Владелец разрешил публикацию с этими предупреждениями; само
предупреждение не является разрешением правообладателя. См.
[PUBLICATION_REVIEW_RU.md](PUBLICATION_REVIEW_RU.md),
[LICENSE_DATA.txt](LICENSE_DATA.txt) и `THIRD_PARTY_NOTICES.txt`. MIT
[LICENSE](LICENSE) относится к собственному коду и не заменяет условия
словаря, шрифтов и библиотек.
