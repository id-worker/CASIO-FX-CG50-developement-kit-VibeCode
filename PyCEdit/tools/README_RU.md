# Дополнительные файлы PyCEdit

В существующем основном репозитории к 28.10.2026 `PyCEdit/src/main.c`
использует `font6x10.h`, но сам файл шрифта отсутствовал. Здесь добавлены
`src/font6x10.h`, заглушки для host-тестов и дополнительные инструменты.
Сохранённый генератор создаёт тот же заголовок шрифта побайтно; запуск
`gen_assets.py` также перезапишет `selected.bmp` и `unselected.bmp`.

`sh tools/run_host_test.sh` запускает сохранённый интеграционный тест на
компьютере. Нужны компилятор C, pkg-config и заголовки libpng. В этой
подготовительной копии абсолютные пути PNG заменены на относительные; тест
создаёт картинки во временной папке и очищает только её. Это не тест на
калькуляторе и не доказательство побайтной воспроизводимости `.g3a`.

Для сборки аддина нужен совместимый libfxcg/PrizmSDK и его компилятор,
а не только fxSDK + gint. `FXCGSDK` можно задать явно; исходный Makefile
из существующего репозитория также содержит старый локальный путь по умолчанию.
Сам `main.c`, уже лежащий в репозитории, данным архивом не изменяется.

Права на фрагмент выхода `set_menu_return_flag()` требуют проверки; см.
`PyCEdit/PUBLICATION_REVIEW_RU.md`. Не считать все сторонние фрагменты
автоматически перелицензированными под MIT.
