# Инструменты и проверки PyCEdit 1.15

- `sh tools/run_host_test.sh` — интеграционные проверки светлой версии,
  RGB565 в host-VRAM и полных клавиатурных последовательностей для всех
  62 C-заголовков и 18 Python-импортов. Нужны C compiler, pkg-config и libpng
  headers. `SANITIZE=1` включает ASan/UBSan. Переменная
  `PYCEDIT_TEST_IMAGES=/путь/к/папке` сохраняет компьютерные снимки.
- `python3 tools/test_color_contrast.py` проверяет выбранные RGB565 и
  рассчитывает контраст с белым в идеальной sRGB-модели. Физический экран и
  условия освещения не моделируются.
- `python3 tools/test_catalog.py` сверяет 43 PicoC имени с локальным снимком
  `picoc_registered_headers.txt`, проверяет 19 SDK-заголовков и 18 Python
  шаблонов из `python_modules_reference.txt`, уникальность и ширину подписей.
  Это проверка меню, не установленности модулей на реальном приборе.
- `FXCGSDK=/путь/к/PrizmSDK sh tools/run_qemu_test.sh` — проверка SuperH:
  подсветка, языковые состояния и пролистывание обоих каталогов. Casio OS
  `strlen` заменён тестовой функцией, экран и видеопамять эмулируются.
- `python3 tools/gen_theme_icons.py` генерирует две текущие иконки 92×64
  без букв в `selected.bmp` и `unselected.bmp`. Требуется Pillow.
  `icon_renderer.py` — общий код. Для обычного `make` Pillow не нужен.
  `gen_assets.py` генерирует только шрифт; иконки не перезаписывает.
- `tools/fix_g3a.py` вызывается Makefile после mkg3a: с параметром `--icons`
  встраивает точные RGB565-иконки и пересчитывает обе суммы; без параметра
  пересчитывает только суммы. Исполняемый код не меняется.

Ни одна из этих проверок не доказывает читаемость цветов на настоящем LCD,
работу клавиатуры Casio OS или наличие модулей в установленном PythonExtra.
