# PyCEdit 1.12 для Casio fx-CG50

Версия 1.12: интерфейс редактора, диалоги и список файлов
теперь чёрно-белые. Цветная подсветка Python/C не изменялась; выделение текста
показывается чёрной рамкой. Эта сборка ещё не проверена на настоящем приборе.

Сначала сохрани старый `PyCEdit.g3a` и важные `.py`/`.c` на компьютер. Затем
замени аддин новым, безопасно извлеки калькулятор и проверь открытие списка,
создание и редактирование тестового файла, выделение, копирование/вставку,
сохранение, выход через MENU и повторный запуск. Перед проверкой не используй
единственную копию важного файла.

## Сборка

Нужны совместимые `sh3eb-elf-gcc`, libfxcg с `toolchain/prizm_rules`, mkg3a и
Python 3. В WSL/Linux задай `FXCGSDK` (по умолчанию `$HOME/PrizmSDK`), добавь
компилятор и mkg3a в `PATH`, затем в этой папке выполни `make`. Скрипт
`tools/fix_g3a.py` вызывается автоматически после mkg3a; контроль заголовка —
`fxgxa -d PyCEdit.g3a`. Исходный шрифт и host-тесты входят в `src/` и `tools/`.
Конкретная сборка 1.12 сделана GCC 14.1.0 и libfxcg v0.6, без LTO.

`THIRD_PARTY_NOTICES.md` и `licenses/`. Происхождение старой функции выхода
остаётся предметом проверки, см. `PUBLICATION_REVIEW_RU.md`.
