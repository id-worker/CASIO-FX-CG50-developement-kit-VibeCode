# GraphLab 1.06: настройки простыми словами

Аддин работает на английском, а это русская памятка к каждому пункту. Версия 1.06 ещё не проверена на настоящем fx-CG50.

## Как открыть и изменить

В главном меню нажми `F4 PARAM` или в редакторе / на графике нажми `OPTN`. Выбирай строку стрелками `UP`/`DOWN`. У переключателей используй `LEFT`/`RIGHT`; у числового поля нажми `EXE`, очисти старое значение через `SHIFT`+`DEL`, введи новое и подтверди `EXE`. Десятичный разделитель — точка. В настройках `F4 HELP` показывает короткую английскую справку, `F5 SAVE` записывает изменения, `EXIT` возвращает назад. Меню прокручивается.

## Все пункты OPTN

| Как написано | Что означает и когда менять |
|---|---|
| **2D line width (px)** | Толщина линии на 2D-графике в пикселях: от 1 до 5. Больше — линия заметнее. На точность вычисления не влияет. На самом 2D-графике работает также `SHIFT`+`F2`. |
| **3D clip half-size** | Половина стороны куба, в котором ищется 3D-поверхность. Например, `3` означает от −3 до +3 по каждой из трёх осей. В 1.06 центр **всегда `(0,0,0)`** и движение камеры его не меняет. Больший размер показывает более далёкие части, но при той же сетке маленькие детали станут грубее и могут пропасть. Допустимо `0.001…10000`; при отсутствии старых настроек исходное значение — `3`. |
| **Parameter a** | Числовое значение буквы `a` в формулах. Например, задай `a=2` в этой строке и построй `y=a*x`: получится `y=2*x`. |
| **Parameter b** | То же для буквы `b`. Например, `y=x+b` сдвигает прямую по вертикали. |
| **Parameter c** | То же для буквы `c` в обычных 2D/3D-формулах. В режиме фрактала `c` имеет специальное комплексное значение, описанное ниже, и берётся не из этой строки. |
| **Parameter t** | Ещё один числовой параметр `t` в формулах. Сам по себе со временем не меняется и анимацию не запускает. Параметры `a`, `b`, `c`, `t` при первом запуске равны нулю. |
| **Julia c: real** | Действительная часть постоянной комплексной величины `c` для фрактала в режиме **Julia**. При стандартном значении здесь `−0.8`. |
| **Julia c: imaginary** | Мнимая часть той же величины. При стандартном значении `0.156` получается `c = −0.8 + 0.156i`. Оба поля используются только в режиме Julia; в режиме `c=pixel` значение `c` берётся из координат каждой точки экрана. |
| **Fractal escape radius** | Порог «точка улетела»: после каждой итерации проверяется модуль комплексного `z`; если `|z|` больше порога, точка считается вышедшей. По умолчанию `4`, допустимо от `1` до `1000`. Влияет на цвета и результат. Для произвольной придуманной формулы один порог не гарантирует математически верную границу. |
| **X period (0 = off)** | Необязательное ускорение для поля, которое действительно периодично по x. `0` выключает его — это безопасный выбор, если не уверен. Например, для `y=sin(x)` полный период — `2*pi`. Программа может повторно использовать часть вычислений, только если период согласуется с сеткой; ускорение не гарантировано. Если указан неверный период, график может получиться неправильным. Это не размер куба и не перемещение камеры. |
| **2D accuracy (px)** | Порог уточнения пересечения для **неявного 2D-контура**: `0.25`, `0.5`, `1` или `2` экранных пикселя. Меньше — обычно точнее, но больше вычислений. По умолчанию `0.5`. Это не толщина линии и не строгая гарантия точности всей картинки; для распознанного `y=f(x)` используется другой, быстрый путь. |
| **3D renderer** | Метод построения: `VOXEL` — кубики, обычно быстрее и подходит также для неравенств; `RAY` — поиск поверхности лучами, обычно гладче и медленнее. В обоих случаях возможен пропуск мелких деталей. Если включено 3D-неравенство, программа временно использует воксели даже при выборе `RAY`; `*` у `V…` напоминает об этом. |
| **Voxel grid divisions** | Число ячеек `N` по каждой стороне 3D-куба: целое от `6` до `64`, исходно `20`. Больше N — кубики мельче, но вычислений и расхода памяти больше. Общее количество ячеек растёт примерно как `N³`. На 3D-экране `F4` переключает типичные размеры `V6`, `V12`, `V20`, `V32`, `V48`, `V64`. |
| **Voxel step (world)** | Размер одного кубика в **мировых координатах**, а не в пикселях. Это не отдельная вторая сетка: `шаг = 2 × clip half-size / N`. При вводе шага программа подбирает ближайшее допустимое целое N, поэтому точный результат может немного отличаться. Например, при R=3 и N=20 шаг равен 0.3; при R=10 и N=20 — уже 1.0. |

Исходные значения относятся к свежему запуску без импортированных сохранений. При переходе со старой версии сохраняются твои прежние параметры.

## Качество на самих графиках

- **2D `F4 DETAIL`, D1–D3:** плотность расчётной сетки неявного графика. Это не толщина линии; не для всех явных формул смена вызывает новый расчёт.
- **3D `F4 DETAIL`, V…:** число делений воксельной сетки. Больше — потенциально подробнее и медленнее. В режиме лучей вместо этого `Q12`, `Q20`, `Q32`, `Q48` обозначают вспомогательную сетку поиска. Большое Q не гарантирует обнаружение всех деталей.
- **Фрактал `F4 DETAIL`:** размер рисуемого блока в пикселях. `DETAIL 1 px` подробнее, чем `DETAIL 4 px`, но обычно считается медленнее. Значение видно над готовым изображением. `F3 ITER` в меню фрактала задаёт предельное число итераций: больше может показать больше деталей, но увеличивает время.

После первого `PLOT` выбирается вид, второй `PLOT` или `EXE` строит картинку. В 3D после движения готовая модель скрывается до следующего `PLOT`/`EXE`. Во фрактале изменение области или детализации запускает новый расчёт.

## Если 3D-модель пропала

1. Нажми `F2 RESET`, затем `PLOT`. В 1.06 камера не улетает далеко от начала только потому, что куб увеличен.
2. Убедись, что формула включена (`F2 ON/OFF` в списке) и попадает в диапазон `−R…+R`.
3. Для небольшой фигуры верни `3D clip half-size = 3` или другое разумное значение. Если увеличить R, а N не менять, кубики тоже станут больше.
4. Попробуй увеличить `Voxel grid divisions` или переключить `3D renderer` на `RAY` для уравнения. Неравенства всё равно строятся вокселями.
5. Плоскость перед камерой, конечная сетка и 32-битная арифметика остаются ограничениями. Абсолютно бесконечную область и обнаружение всех тонких деталей программа не гарантирует.
