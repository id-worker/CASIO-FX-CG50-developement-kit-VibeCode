# Notes on the synthetic RAY benchmark

`bench_heath115.c` is the scene source used for the 1.14/1.15 comparison. It is a **test add-in**, not the released GraphLab application. The user's eye coordinates were entered, but the actual view direction was unknown; yaw=0.75 and pitch=0.55 were assumed. Preview capture step is 4, the grid is initially empty, clip radius is 10 and RAY Q is 8. The first surface is implicit and the second is explicitly compiled as height. Both versions used the same fxSDK/gint 2.11 toolchain and options.

The test was compiled separately against the `expr.c`, `ray.c`, `trigfast.c`, `preview3d.c` and `plot.c` of each release. The small build used `-Os` and the standard fxSDK `GenerateG3A` target. Scene input and output are in the test code; `gstats`, `g_rc` and the empty, non-inlined `glbench_done()` are measurement hooks. In a headless interpreter, count loop iterations only between the entry of `ray3d_render_ex` and its return, then save all `396*224` RGB565 pixels at `gint_vram` when `glbench_done()` is reached. Use symbol addresses from each respective ELF, not hard-coded addresses from another build.

The test used [Heath's experimental emulator](https://github.com/Heath123/casio-emu), commit `5d34e298b94be65f7ab0505d3c0f9b9ed802ac4b`, with a custom headless front end and instrumentation. The upstream emulator and these local emulator changes are **not included** in the release. This is not cycle-accurate: an interpreter loop iteration is neither a CG50 clock cycle nor a duration, and Casio OS / real keyboard / LCD / storage are not simulated by this harness. Do not estimate hardware seconds from this count.

For the checked builds, the old/new values were 2,682,298,652 / 2,068,886,017 iterations and the framebuffer bytes were equal (SHA-256 `15c59ec49a86f4f00527a8630521837a0b5195c20b17ca33a4b85371cd89be3f`). Machine-code layout, compiler or instrumentation changes can change counts. The code itself and its tests are provided under the GraphLab MIT licence; consult the upstream project's own terms before redistributing its emulator.
