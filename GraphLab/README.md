# GraphLab 1.06 для Casio fx-CG50

Экспериментальный офлайн-аддин для построения 2D/3D-уравнений и неравенств,
фракталов и редактирования математических выражений. Интерфейс аддина —
английский, [полное руководство и управление — на русском](README_RU.md).

**Статус:** версия 1.06 проверена на компьютере и в SH QEMU с искусственными
нажатиями, но пока не проверена на настоящем fx-CG50. Скорость и доступная
память на калькуляторе не измерены. Перед установкой сохрани предыдущий `.g3a`
и оба файла `GLAB3_A.DAT` / `GLAB3_B.DAT`, если они есть.

- Готовый файл: [`GraphLab.g3a`](GraphLab.g3a).
- SHA-256: `dd52bdfc900ed0d3517c50c77243f398b2d3a245d6ee06445c83b144bb3458bd`.
- [Быстрая проверка редактора](БЫСТРАЯ_ПРОВЕРКА_RU.md) и
  [пояснение настроек](НАСТРОЙКИ_RU.md).
- Исходники `src/`, тесты `tests/`, иконки `assets-cg/`.
- Сборка с fxSDK/gint: `fxsdk build-cg`; подробности и ограничения в руководстве.
