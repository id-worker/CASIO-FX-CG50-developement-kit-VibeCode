# Инструменты набора v1.02

- `python3 release_tools/verify_icons.py` сверяет текущие файлы в `releases/`
  с копиями в проектах, контрольные суммы G3A, идентификаторы, имена, цветовые
  значения иконок и зафиксированные hashes. Для PyCEdit проверяется новое имя
  **PyCEdit** и совпадение обеих иконок с 1.14; у четырёх остальных программ
  сохранён исполняемый payload. Достаточно стандартного Python 3.
- `python3 release_tools/package_release.py --output ../cg50-release-files`
  собирает один небольшой установочный ZIP и отдельные G3A/TDIC/SHA256SUMS.
  Выходную папку выбери вне репозитория. Скрипт проверяет CRC и байты архива;
  SDK, пользовательские фотографии и приватные копии в архив не добавляются.
- `create_icons.py` и `create_gallery.py` — генераторы исходной галереи;
  нужны Pillow и DejaVu Sans (пути шрифтов в генераторе галереи указаны для
  Linux). При другом окружении результаты генерации могут отличаться.
  Генерация `Icons/` сама по себе не обновляет иконки проектов или G3A.

Это программные проверки, не проверка Casio OS и физического LCD.
