 БЫСТРАЯ БИБЛИОТЕКА gint + time ДЛЯ WINDOWS PYTHON IDLE (БЕЗ pip install)
========================================================================

КАК ПОЛЬЗОВАТЬСЯ В WINDOWS PYTHON IDLE:
  Вариант А (для одной папки со скриптами):
    Положи файлы `gint.py` и `utime.py` в ту же папку, где лежат твои
    программы для калькулятора (например, рядом с `obj_viewer.py` и `spot.obj`).
    Открой скрипт в Python IDLE и нажми F5!

  Вариант Б (чтобы работало вообще из любой папки на ПК):
    Скопируй `gint.py` и `utime.py` в папку `Lib\site-packages` твоего
    установленного Python на Windows.

ПОЧЕМУ НЕТ ФАЙЛА С ИМЕНЕМ `time.py`?
  В стандартном Python на Windows модуль `time` встроен прямо в ядро интерпретатора,
  и сам IDLE использует его при старте. Поэтому наш `gint.py` при строке
  `import gint` АВТОМАТИЧЕСКИ дописывает в стандартный модуль `time` все
  функции MicroPython / PythonExtra:
    - time.ticks_ms(), time.ticks_us(), time.ticks_cpu()
    - time.ticks_add(t, d), time.ticks_diff(t1, t2)
    - time.sleep_ms(ms), time.sleep_us(us)
  А если в каком-то скрипте написано `import utime`, для этого рядом лежит `utime.py`!
  Также автоматически поддерживаются калькуляторные пути вида `open("/spot.obj")`
  и `open("\\\\fls0\\file.txt")` — они ищутся прямо в папке твоего скрипта.

ГОРЯЧИЕ КЛАВИШИ ОКНА НА ПК:
  Стрелки         -> Стрелки калькулятора
  Enter / Esc     -> EXE / EXIT
  Backspace / Del -> DEL
  F1 .. F6        -> F1 .. F6
  0 .. 9 (и Num)  -> Цифры KEY_0 .. KEY_9
  + - * / . ,     -> Знаки операций
  ` (тильда/ё)    -> Кнопка (-) KEY_NEG
  Shift / Ctrl    -> KEY_SHIFT / KEY_ALPHA
  Tab / Home      -> OPTN / MENU
  Буквы A .. Z    -> Физические ALPHA-клавиши Casio (имена файлов вводятся с клавиатуры!)
  F9              -> Масштаб окна (1x / 2x / 3x / 4x)
  F12             -> Сохранить BMP-скриншот экрана калькулятора (396x224)
