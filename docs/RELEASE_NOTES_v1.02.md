# Casio fx-CG50 Add-in Suite 1.02

Обновление общего набора для **Casio fx-CG50**. Версия набора — `v1.02`;
номера самих приложений остаются отдельными.

> **Важно:** эти файлы прошли программные проверки, но полная проверка именно
> новых сборок на настоящем калькуляторе не подтверждена. Новые цвета PyCEdit
> и отображение выделенных иконок нужно проверить на физическом LCD. QEMU и
> компьютерные изображения не заменяют устройство. Перед установкой сохрани
> старые аддины и свои данные.

## Что нового

- **Новые иконки** GraphLab, Wireworld, PyCEdit, Translator и ObjView: без
  букв, с графитовой плашкой и нейтральным серым выбранным состоянием.
  Подписи рисует меню калькулятора; возможное собственное синее выделение
  Casio OS ещё нужно проверить на приборе.
- **PyCEdit 1.15** — светлая версия с именем **PyCEdit** в меню. Для Python
  и C функции выделяются синим, строки — красным. Обрабатываются также
  многострочные строки Python и комментарии C. Новый набор проверочных файлов
  `COLORPY.py` и `COLORC.c` лежит в `Examples/` внутри ZIP.
- В PyCEdit **F3 SYM → F5 PYMOD** содержит 18 шаблонов для вставки `import`;
  **F3 SYM → F4 LIBS** содержит 62 C/PicoC/SDK заголовка. Список Python не
  устанавливает модули и не гарантирует их наличие; `[FILE]` отмечает
  внешний файл, `[SDK]` не обещает доступность заголовка в Utilities PicoC.
- **GraphLab 1.09**, **Wireworld 1.65**, **Translator 1.11** и **ObjView
  2.23** сохраняют прежнюю исполняемую часть: у них изменены изображения
  иконок и контрольные суммы G3A. `TDIC.DAT` не изменился.

PythonExtra и Utilities поддерживаются отдельно и этим выпуском не изменялись.

## Загрузка и установка

`CG50_Kit_v1.02.zip` — небольшой установочный набор с пятью `.g3a`, словарём,
моделью `torus.obj`, примерами и лицензионными уведомлениями. Также можно
скачать отдельные `.g3a` и `TDIC.DAT`. Исходники доступны в репозитории и
автоматических исходных архивах GitHub; Windows SDK в этот релиз не входит.

1. Сделай резервную копию прежних `.g3a`, `.py`, `.c`, моделей и сохранений
   (`GLAB*.DAT`, `GLQ8*.DAT`, `Wireworld.ww`).
2. Скопируй нужные `.g3a` в корень памяти калькулятора. Для Translator туда
   же скопируй `TDIC.DAT`.
3. Если раньше устанавливал `PyCLite.g3a`, после резервного копирования
   удали **только старый аддин** и скопируй `PyCEdit.g3a`. Если старый
   `PyCEdit.g3a` уже есть, замени его после сохранения копии. Свои `.py` и
   `.c` удалять не нужно.
4. Для примера ObjView скопируй `torus.obj` и введи `torus` без расширения.
   Ввод поддерживает латиницу, цифры, `.`, `-`, `_` и `/`; пробелы и
   кириллица в имени не вводятся. В окне модели ALPHA влияет на скорость
   перемещения, не вращения.

GraphLab 1.09 импортирует старые настройки в отдельный `GLAB4_A/B.DAT`;
старые версии не читают этот журнал.

## Проверки и лицензии

Все пять G3A прошли **12/12** структурных проверок `fxgxa`, иконки и хеши
сверены с исходными изображениями. Две независимые сборки PyCEdit 1.15 дали
одинаковый файл в проверенной среде. Host ASan/UBSan, 500 случайных рендеров,
C/Python-каталоги и SH/QEMU прошли; это не проверка Casio OS или LCD.
Дополнительные проверки остальных программ описаны в их проектах. SHA-256
файлов релиза указан в `SHA256SUMS.txt`; в ZIP есть отдельный манифест.

Собственный код — MIT с указанием **Alex Work**; условия сторонних библиотек,
шрифтов, моделей и данных словаря сохранены в `notices/` и репозитории.
Точное происхождение части словаря Translator и права на фрагмент
`set_menu_return_flag()` остаются открытыми вопросами; предупреждение само
по себе не даёт разрешение правообладателя. Прежние релизы v1.01 и v1.0
сохраняются.
