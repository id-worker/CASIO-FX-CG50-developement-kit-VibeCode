1. КАК УСТРОЕН PICOC НА КАЛЬКУЛЯТОРЕ (ВАЖНЫЕ ПРАВИЛА И ОТЛИЧИЯ ОТ ПК)
================================================================================

PicoC — это компактный интерпретатор языка C, встроенный прямо в аддин
Utilities.g3a. Чтобы запустить программу, сохрани её на калькулятор с
расширением .c (например, через PyCEdit), открой Utilities -> File Manager,
наведи курсор на файл .c и нажми EXE.

ПЯТЬ ГЛАВНЫХ ПРАВИЛ (ЗНАТЬ ОБЯЗАТЕЛЬНО!):

1) ФУНКЦИЯ main() НЕ ВЫЗЫВАЕТСЯ САМА!
   PicoC выполняет файл сверху вниз как скрипт (как Python). Если ты объявил
   `int main() { ... }`, то в самой последней строчке файла обязательно допиши
   вызов:
       main();
   (Либо вообще пиши команды прямо на верхнем уровне без `main()`).

2) НЕ ПИШИ #include <stdio.h>, <stdlib.h>, <string.h>!
   На калькуляторе базовые функции (`printf`, `sprintf`, `malloc`, `free`,
   `strcpy`, `strlen`, `memcpy`, `memset` и др.) УЖЕ встроены глобально!
   Попытка написать `#include <stdio.h>` вызовет ошибку "can't include file",
   потому что директива `#include` нужна ТОЛЬКО для библиотек калькулятора:
       #include <fxcg/display.h>
       #include <utilities/graphicsProvider.h>
   или для твоих собственных файлов на флеше: `#include "\\fls0\\mylib.c"`.

3) ТОЛЬКО ЦЕЛЫЕ ЧИСЛА (НЕТ float И double)!
   Сборка PicoC для Prizm скомпилирована с флагом `NO_FP` (без плавающей точки).
   Используй типы: `int`, `unsigned int`, `short`, `unsigned short`, `char`,
   `unsigned char`, указатели (`int*`, `char*`, `void*`), массивы и `struct`.
   Совет: если нужна дробная физика/3D — используй фиксированную точку
   (например, храни координаты умноженными на 256: `x_screen = x_fp >> 8`).

4) ОПЕРАТОРЫ && И || ВЫЧИСЛЯЮТ ОБЕ ЧАСТИ!
   В обычном C в условии `if (ptr != NULL && ptr->x == 5)` правая часть не
   выполняется, если `ptr == NULL`. В PicoC вычисляются ОБЕ части сразу!
   Поэтому при проверке указателей или границ массива пиши вложенные `if`:
       if (ptr != NULL) {
           if (ptr->x == 5) { ... }
       }

5) НЕТ КЛАССОВ C++ (`class`), ВМЕСТО НИХ — СТРУКТУРЫ C (`struct`)!
   PicoC понимает чистый язык C, а не C++. Роль «классов» с полями выполняют
   структуры `struct` (например, `struct Menu`, `struct FsInfo`), а роль
   «конструкторов» — функции `initMenu(&m)` из `<utilities/structInit.h>`.

2. ВСТРОЕННАЯ СТАНДАРТНАЯ БИБЛИОТЕКА C (ДОСТУПНА СРАЗУ БЕЗ #include)
================================================================================

Встроенные глобальные константы (доступны всегда):
  NULL   = 0
  FALSE  = 0
  TRUE   = 1

--- Ввод, вывод и завершение программы ---

  void printf(char *fmt, ...);
      Печатает форматированный текст (%d, %u, %x, %s, %c) во внутренний буфер
      PicoC (размер буфера — 4096 байт). Когда скрипт завершится, Utilities
      автоматически откроет текстовое окно с этим выводом.

  char *sprintf(char *buf, char *fmt, ...);
      Форматирует строку в буфер `buf` (незаменимо для вывода очков, координат
      и чисел на графический экран через PrintMini / multiPrintMini).

  void exit(int code);
      Мгновенно завершает выполнение скрипта и возвращает управление в Utilities
      (безопасно выходит даже из глубоко вложенных функций).

  char *gets(char *buf); / int getchar();
      Заглушки консольного ввода (на калькуляторе возвращают NULL / 0; для
      реального ввода используй `GetKey`, `key_down` или `doTextInput`).

--- Управление памятью кучи PicoC (общий пул стека + кучи = 128 КБ) ---

  void *malloc(int size);            // выделить `size` байт
  void *calloc(int count, int size); // выделить `count * size` байт и обнулить
  void *realloc(void *ptr, int sz);  // изменить размер блока
  void free(void *ptr);              // освободить блок

--- Строки и блоки памяти ---

  int   strlen(char *s);                        // длина строки в байтах
  void  strcpy(char *dst, char *src);           // копировать строку
  void  strncpy(char *dst, char *src, int n);   // копировать не более n байт
  void  strcat(char *dst, char *src);           // дописать src в конец dst
  int   strcmp(char *a, char *b);               // 0 если равны, <0 или >0
  int   strncmp(char *a, char *b, int n);       // сравнить первые n символов
  char *index(char *s, int ch);                 // аналог strchr (первое вхожд.)
  char *rindex(char *s, int ch);                // аналог strrchr (последнее)
  void  memset(void *dst, int byte_val, int n); // заполнить память байтом
  void  memcpy(void *dst, void *src, int n);    // скопировать n байт
  int   memcmp(void *a, void *b, int n);        // сравнить n байт памяти

3. КОНСТАНТЫ: ЦВЕТА RGB565, КЛАВИШИ, РЕЖИМЫ ФАЙЛОВ, ЧАСТОТЫ CPU
================================================================================

ВАЖНО: в PicoC предопределены только `NULL`, `TRUE`, `FALSE`, а также
перечисления `TEXT_COLOR_*` и `TEXT_MODE_*`. Все остальные константы из SDK
(коды клавиш, цвета RGB565, флаги файлов) передаются числами или объявляются
через `#define` в начале твоего скрипта!

--- 3.1 Предопределённые константы (уже известны PicoC без #define) ---

  Текстовые цвета (для PrintXY, mPrintXY, multiPrintXY, Menu):
    TEXT_COLOR_BLACK  = 0      TEXT_COLOR_RED    = 4
    TEXT_COLOR_BLUE   = 1      TEXT_COLOR_PURPLE = 5
    TEXT_COLOR_GREEN  = 2      TEXT_COLOR_YELLOW = 6
    TEXT_COLOR_CYAN   = 3      TEXT_COLOR_WHITE  = 7

    TEXT_MODE_AND                    = 0x21

  Версии API:
    UTILITIES_API_VERSION = 1
    FXCG_API_VERSION      = 1

--- 3.2 Геометрия экрана и 16-битные цвета RGB565 ---

  Разрешение экрана: 384 x 216 пикселей (верхние 24 пикселя — статусная строка,
  если она не отключена через `EnableStatusArea(3)`).
  Формат пикселя в VRAM (`unsigned short`): 5 бит Red, 6 бит Green, 5 бит Blue:
    color = ((r & 31) << 11) | ((g & 63) << 5) | (b & 31);
  Либо готовой функцией из `<utilities/graphicsProvider.h>` (r,g,b от 0 до 255):
    color = drawRGB24toRGB565(r, g, b);

  Готовый набор #define цветов RGB565 для копирования в скрипт:
    #define C_BLACK    0x0000
    #define C_WHITE    0xFFFF
    #define C_RED      0xF800
    #define C_GREEN    0x07E0
    #define C_BLUE     0x001F
    #define C_YELLOW   0xFFE0
    #define C_CYAN     0x07FF
    #define C_MAGENTA  0xF81F
    #define C_ORANGE   0xFD20
    #define C_DARKGRAY 0x4208
    #define C_GRAY     0x8410
    #define C_LTGRAY   0xC618

--- 3.4 Коды аппаратной матрицы клавиш (0xA44B0000 — мгновенно, для игр!) ---

  `GetKey` ждёт нажатия и не видит диагонали или зажатие нескольких кнопок.
  Для игр читай регистр клавиатуры напрямую через эту маленькую функцию:

    int key_down(int code) {
        unsigned short *kreg = (unsigned short *)0xA44B0000;
        int row = code % 10;
        int col = code / 10 - 1;
        int word = row >> 1;
        int bit = col + ((row & 1) << 3);
        return (kreg[word] & (1 << bit)) != 0;
    }

  Таблица кодов `code` для `key_down(code)`:

4. СТРУКТУРЫ («КЛАССЫ» В C) И ИХ ИНИЦИАЛИЗАЦИЯ (<utilities/structInit.h>)
================================================================================

В C структуры (`struct`) заменяют классы с данными. Две структуры уже вшиты в
PicoC при подключении `<fxcg/display.h>`:

  1) struct display_fill {
         int x1; int y1; int x2; int y2;
         unsigned char mode; /* 0=стереть белым, 1=закрасить цветом, 2=инверт */
     };

  2) struct scrollbar {
         unsigned int I1;               /* 0 */
         unsigned int indicatormaximum; /* всего элементов */
         unsigned int indicatorheight;  /* видимых элементов на экране */
         unsigned int indicatorpos;     /* текущая позиция сверху */
         unsigned int I5;               /* 0 */
         unsigned short barleft;        /* обычно 378 */
         unsigned short bartop;         /* верх в пикселях */
         unsigned short barheight;      /* высота в пикселях */
         unsigned short barwidth;       /* обычно 6 */
     };

Остальные структуры для работы с файлами и готовыми GUI-виджетами Utilities
достаточно скопировать в начало своего скрипта, а обнулять их значениями по
умолчанию через заголовок:

5.1 <fxcg/display.h> — Экран, VRAM (384x216 RGB565), пиксели, шрифты, окна
--------------------------------------------------------------------------------
Экран работает по схеме двойной буферизации:
  1) Все функции рисования пишут в оперативный видеобуфер VRAM (384x216 точек).
  2) На физическом экране изменения появятся ТОЛЬКО после вызова `Bdisp_PutDisp_DD();`!

Главные функции экрана и VRAM:
  void *GetVRAMAddress(void);
      Возвращает прямой указатель на видеобуфер `384 * 216` пикселей RGB565.
      Самый быстрый способ рисовать пиксели в играх и 3D:
          unsigned short *vram = (unsigned short *)GetVRAMAddress();
          vram[y * 384 + x] = 0xF800; /* красный пиксель в (x, y) */

  void Bdisp_EnableColor(int mode);
      1 = включить полный 16-битный цвет (65536 цветов), 0 = 8-цветный режим.

  void EnableStatusArea(int mode);
      Управление верхней 24-пиксельной статусной полоской ОС:
      3 = ОТКЛЮЧИТЬ статус-бар (отдаёт тебе весь экран 384x216!),
      0 = включить обратно перед выходом из программы (`EnableStatusArea(0);`).

  void Bdisp_AllClr_VRAM(void);
      Очищает весь VRAM белым цветом.

  void Bdisp_Fill_VRAM(int color, int mode);
      Заливает область экрана цветом RGB565 (`mode`: 3 или 4 — весь экран).

  void Bdisp_PutDisp_DD(void);
      Копирует весь буфер VRAM (384x216) на физический дисплей.

  void Bdisp_PutDisp_DD_stripe(int y1, int y2);
      Отправляет на дисплей только полосу строк от `y1` до `y2` (быстрее!).

  void Bdisp_SetPoint_VRAM(int x, int y, int color);
  unsigned short Bdisp_GetPoint_VRAM(int x, int y);
      Поставить / прочитать цвет одного пикселя в VRAM.

  void DirectDrawRectangle(int x1, int y1, int x2, int y2, unsigned short col);
      Заливает прямоугольник напрямую на дисплей (минуя VRAM). Для рисования
      в VRAM удобнее `drawRectangle(x, y, w, h, col)` из `graphicsProvider.h`.

  void Bdisp_AreaClr(struct display_fill *area, unsigned char target,
                     unsigned short color);
      Заливка/очистка/инверсия области `area` (`target = 1` для VRAM).

  void SaveVRAM_1(void); / void LoadVRAM_1(void);

  void DrawFrame(int color);

Вывод текста и спрайтов в <fxcg/display.h>:

      ВНИМАНИЕ: системная `PrintXY` пропускает первые 2 байта строки `msg`!

      используй удобную `mPrintXY(col, row, "Hello", mode, color)` из

  void PrintMini(int *x, int *y, char *str, int mode_flags,
                 unsigned int xlimit, int P6, int P7,
                 int fg_color, int bg_color, int writeflag, int P11);
      Системный мелкий пропорциональный шрифт (~18 пикселей в высоту) по точным

5.3 <fxcg/file.h> — Файловая система флеша (\\fls0\) и Main Memory (MCS)
--------------------------------------------------------------------------------
ВАЖНЫЕ ПРАВИЛА ФАЙЛОВОЙ СИСТЕМЫ CASIO BFILE:
  1) Все пути передаются в `Bfile_*` не как `char*`, а как 16-битный массив
     `unsigned short path[64]`, сконвертированный функцией `Bfile_StrToName_ncpy`!
  2) Перед созданием файла (`Bfile_CreateEntry_OS`), если такой файл уже может
     существовать, ОБЯЗАТЕЛЬНО сначала удали старый через `Bfile_DeleteEntry`!
  3) Нельзя создавать файл размера `0` байт — размер `size` должен быть `>= 1`!
  4) Во время работы `Bfile_FindFirst` / `FindNext` НЕ вызывай `Create` / `Delete` /
     `Rename` до тех пор, пока не закроешь поиск через `Bfile_FindClose(fh)`!

Основные функции флеш-памяти (`\\fls0\`):
  void Bfile_StrToName_ncpy(unsigned short *dst16, char *src_ascii, unsigned int max);
      Переводит ASCII-путь `"\\\\fls0\\data.bin"` в 16-битный формат ОС.

  void Bfile_NameToStr_ncpy(char *dst_ascii, unsigned short *src16, unsigned int max);
      Переводит 16-битное имя файла обратно в обычную строку `char*`.

  int Bfile_CreateEntry_OS(unsigned short *path16, int mode, int *size);
      Создаёт файл (`mode = 1`, `size` — указатель на `int` с размером в байтах)
      или папку (`mode = 5`, вместо `&size` можно передать `NULL`).
      Возвращает `>= 0` при успехе, `< 0` при ошибке.

  int Bfile_OpenFile_OS(unsigned short *path16, int mode, int zero);
      Открывает файл (`mode`: `0`=READ, `2`=WRITE, `3`=READWRITE; третий аргумент `0`).
      Возвращает дескриптор `handle >= 0` (или `< 0`, если файл не найден).

  int Bfile_GetFileSize_OS(int handle);
      Возвращает размер открытого файла в байтах.

  int Bfile_ReadFile_OS(int handle, void *buf, int size, int readpos);
      Читает `size` байт в `buf`. `readpos = 0` — читать с начала файла;
      `readpos = -1` — продолжать чтение с текущей позиции курсора!

  int Bfile_WriteFile_OS(int handle, void *buf, int size);
      Записывает `size` байт из `buf` в открытый файл.

  int Bfile_SeekFile_OS(int handle, int pos);
  int Bfile_TellFile_OS(int handle);
      Перемещает позицию чтения/записи в файле и узнаёт текущее смещение.

  int Bfile_CloseFile_OS(int handle);
      Обязательно закрывает открытый файл!

  int Bfile_DeleteEntry(unsigned short *path16);
  int Bfile_RenameEntry(unsigned short *old_path16, unsigned short *new_path16);
      Удалить или переименовать файл/папку.

  int Bfile_FindFirst_NON_SMEM(char *mask16, int *find_handle,
                               char *found16, void *fsinfo_ptr);
  int Bfile_FindNext_NON_SMEM(int find_handle, char *found16, char *fsinfo_ptr);
  int Bfile_FindClose(int find_handle);
      Перебор файлов по маске (например `"\\\\fls0\\*.txt"`). Возвращает `0`,

/* game_template.c — стрелки двигают шар (с диагоналями!), EXIT выходит */
#include <fxcg/display.h>
#include <fxcg/system.h>
#include <fxcg/rtc.h>
#include <utilities/graphicsProvider.h>

int key_down(int code) {
    unsigned short *kreg = (unsigned short *)0xA44B0000;
    int row = code % 10;
    int col = code / 10 - 1;
    int word = row >> 1;
    int bit = col + ((row & 1) << 3);
    return (kreg[word] & (1 << bit)) != 0;
}

int main() {
    int x = 192;
    int y = 108;
    int score = 0;
    char hud[64];

    Bdisp_EnableColor(1);
    EnableStatusArea(3); /* Весь экран 384x216 наш! */

    /* Ждём, пока отпустят клавишу EXE после запуска из проводника */
    while (key_down(31)) { OS_InnerWait_ms(10); }

    while (!key_down(47)) { /* 47 = EXIT */
        if (key_down(38)) x -= 4; /* LEFT  */
        if (key_down(27)) x += 4; /* RIGHT */
        if (key_down(28)) y -= 4; /* UP    */
        if (key_down(37)) y += 4; /* DOWN  */
        if (key_down(31)) score++; /* EXE  */

        if (x < 12) x = 12;
        if (x > 371) x = 371;
        if (y < 30) y = 30;
        if (y > 203) y = 203;

        /* Очистка экрана тёмно-синим фоном и шапка */
        drawRectangle(0, 0, 384, 216, 0x0008);
        drawRectangle(0, 0, 384, 18, 0x1084);
        sprintf(hud, "X:%d Y:%d  SCORE:%d  [EXE:+1] [EXIT:Quit]", x, y, score);
        multiPrintMini(6, -22, hud, 0xFFFF); /* -22 + 24 = y=2px от верха */

        /* Игрок */
        drawFilledCircle(x, y, 10, 0xFFE0);
        drawFilledCircle(x - 3, y - 3, 3, 0xFFFF);

        Bdisp_PutDisp_DD();
        OS_InnerWait_ms(15);
    }

    EnableStatusArea(0); /* Возвращаем статус-бар ОС */
    return 0;
}

main();

/* menu_demo.c — нативный интерфейс Utilities за пару десятков строк */
#include <fxcg/display.h>
#include <utilities/structInit.h>
#include <utilities/menuGUI.h>

struct MenuItem {
    char *text; int type; int value; int color;
    int isfolder; int isselected; int icon;
};

struct Menu {
    char *statusText; char *title; char *subtitle; int titleColor;
    char *nodatamsg; int startX; int startY; int width; int height;
    int scrollout; int numitems; int type; int selection; int scroll;
    int fkeypage; int numselitems; int returnOnInfiniteScrolling;
    int returnOnLeft; int returnOnRight; int darken; int miniMiniTitle;
    int pBaRtR; struct MenuItem *items;
};

struct Selector {
    char *title; char *subtitle; int value; int max; int min;
    int cycle; int type; int clearVRAM;
};

int main() {
    struct MenuItem items[3];
    struct Menu menu;
    struct Selector sel;
    int speed = 5;
    int sound_on = 1;
    char speed_label[32];
    int i;

    for (i = 0; i < 3; i++) initMenuItem(&items[i]);
    initMenu(&menu);

    menu.title = "My App Menu";
    menu.numitems = 3;
    menu.items = items;

    while (1) {
        Bdisp_AllClr_VRAM();
        sprintf(speed_label, "Set Speed (%d)", speed);
        items[0].text = speed_label;

        items[1].text = "Sound Effect";
        items[1].type = 1; /* 1 = MENUITEM_CHECKBOX */
        items[1].value = sound_on;

        items[2].text = "Quit";

        if (doMenu(&menu, NULL) == 0) break; /* Нажали EXIT */

        if (menu.selection == 1) {
            initSelector(&sel);
            sel.title = "Choose Speed";
            sel.min = 1;
            sel.max = 20;
            sel.value = speed;
            if (doSelector(&sel) == 1) speed = sel.value;
        } else if (menu.selection == 2) {
            sound_on = !sound_on;
        } else if (menu.selection == 3) {
            break;
        }
    }
    return 0;
}

main();

/* file_demo.c — создаёт \\fls0\\score.txt, пишет строку и читает обратно */
#include <fxcg/file.h>

#define CREATEMODE_FILE 1
#define READ            0
#define WRITE           2

int main() {
    unsigned short path16[64];
    char *msg = "HighScore=9500\nPlayer=CASIO\n";
    char read_buf[128];
    int size = strlen(msg);
    int h;
    int n;

    Bfile_StrToName_ncpy(path16, "\\\\fls0\\score.txt", 64);

    /* 1. Удаляем старый файл (если был) и создаём новый нужного размера */
    Bfile_DeleteEntry(path16);
    if (Bfile_CreateEntry_OS(path16, CREATEMODE_FILE, &size) < 0) {
        printf("Ошибка создания файла!\n");
        return 1;
    }

    /* 2. Записываем данные */
    h = Bfile_OpenFile_OS(path16, WRITE, 0);
    if (h >= 0) {
        Bfile_WriteFile_OS(h, msg, size);
        Bfile_CloseFile_OS(h);
    }

    /* 3. Читаем данные обратно */
    memset(read_buf, 0, 128);
    h = Bfile_OpenFile_OS(path16, READ, 0);
    if (h >= 0) {
        n = Bfile_GetFileSize_OS(h);
        if (n > 127) n = 127;
        Bfile_ReadFile_OS(h, read_buf, n, 0);
        Bfile_CloseFile_OS(h);
        printf("Прочитано (%d байт):\n%s", n, read_buf);
    }

    return 0;
}

main();
