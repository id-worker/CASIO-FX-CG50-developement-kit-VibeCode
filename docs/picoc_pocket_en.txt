1. RULES OF PICOC IN UTILITIES.G3A
- Put `main();` at the VERY END of your .c file!
- DO NOT `#include <stdio.h>` or `<stdlib.h>` or
  `<string.h>` - built-in C funcs need NO include!
- NO `float` or `double` (integer math only).
- `&&` and `||` DO NOT short-circuit! Use nested
  `if (p != NULL) { if (p->x) ... }`.
- C uses `struct` (not C++ `class`).

2. BUILT-IN C (NO #include NEEDED)
  Constants: NULL (0), TRUE (1), FALSE (0)
  printf(fmt, ...)        sprintf(buf, fmt, ...)
  exit(code)
  malloc(sz)  calloc(n,s) realloc(p,sz)  free(p)
  strlen(s)   strcpy(d,s) strncpy(d,s,n) strcat(d,s)
  strcmp(a,b) strncmp(a,b,n) index(s,c)  rindex(s,c)
  memset(p,v,n)  memcpy(d,s,n)  memcmp(a,b,n)
  Large OS RAM (>128KB): `#include <fxcg/heap.h>`
    p = sys_calloc(1, bytes);  sys_free(p);

3. RGB565 COLORS & TEXT CONSTANTS
  Screen: 384 x 216 px (`unsigned short` RGB565)
  BLACK=0x0000 WHITE=0xFFFF RED=0xF800 GREEN=0x07E0
  BLUE=0x001F  YELLOW=0xFFE0 CYAN=0x07FF MAG=0xF81F
  GRAY=0x8410  DARK=0x4208   ORANGE=0xFD20
  Predefined enums:
    TEXT_COLOR_BLACK(0) BLUE(1) GREEN(2) CYAN(3)
    RED(4) PURPLE(5) YELLOW(6) WHITE(7)
    TEXT_MODE_NORMAL(0) INVERT(1) TRANSPARENT(0x20)

     EXE=30004  EXIT=30002  DEL=30025  AC=30015
     UP=30018   DOWN=30023  LEFT=30020 RIGHT=30021
     F1..F6 = 30009..30014  OPTN=30008 VARS=30016
     SHIFT=30006 ALPHA=30007  '0'..'9'=0x30..0x39

  B) Fast Game Matrix (0xA44B0000, non-blocking):
     int key_down(int c) {
       unsigned short *r=(unsigned short*)0xA44B0000;
       int row=c%10, col=c/10-1;
       return (r[row>>1]&(1<<(col+((row&1)<<3))))!=0;
     }
